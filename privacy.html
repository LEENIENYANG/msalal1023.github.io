隱私權政策

tw-asset-tracker ・ 最後更新：2026 年 9 月 28 日

1. 適用範圍

tw-asset-tracker（以下稱「本程式」）是在使用者本人電腦上執行的個人自用程式，只供開發者本人使用， 不對外提供服務。

2. 存取的資料

本程式透過 Google OAuth 取得 Gmail 唯讀權限 （https://www.googleapis.com/auth/gmail.readonly）， 只搜尋並讀取特定銀行、券商、投信寄送的電子對帳單與通知信件，以及其 PDF 附件。

3. 使用方式

  • 對帳單附件下載到使用者本人的電腦，在本機解析成帳戶餘額、持倉與交易紀錄。
  • 本程式不會修改、刪除或寄出任何郵件。
  • 取得的資料只用於使用者本人的資產統計與記帳，不作其他用途。

4. 資料儲存

所有資料（包含對帳單檔案、解析結果、授權憑證）都存放在使用者本人的電腦， 不會上傳到任何伺服器或第三方服務。

5. 資料分享

本程式不會將任何資料分享、出售或轉讓給任何第三方。

6. 撤銷存取與刪除資料

使用者可隨時在 Google 帳戶的 第三方應用程式與服務 移除本程式的存取權， 並刪除電腦上的資料資料夾，即完全移除本程式取得的資料。

7. Google API 服務使用者資料政策

本程式對 Google API 所取得資訊的使用與傳輸，遵守 Google API Services User Data Policy， 包含其中的 Limited Use（有限使用）規範。

8. 聯絡方式

如有疑問，請透過本網站所屬的 GitHub 帳號聯絡。

Privacy Policy

tw-asset-tracker ・ Last updated: September 28, 2026

  1. tw-asset-tracker ("the app") is a personal tool that runs on its developer's own computer and is used only by the developer. It is not offered as a service to anyone else.
  2. The app requests read-only Gmail access (https://www.googleapis.com/auth/gmail.readonly) and only searches for and reads e-statements and notices sent by specific banks, brokerages and fund companies, including their PDF attachments.
  3. Attachments are downloaded to the user's own computer and parsed locally into balances, holdings and transactions. The app never modifies, deletes or sends email, and uses the data only for the user's own asset tracking and bookkeeping.
  4. All data, including statement files, parsed results and authorization tokens, is stored only on the user's own computer and is never uploaded to any server or third-party service.
  5. The app does not share, sell or transfer any data to third parties.
  6. Access can be revoked at any time from the Google Account third-party apps & services page; deleting the local data folder removes all data the app obtained.
  7. tw-asset-tracker's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
  8. For questions, please contact the GitHub account that owns this site.
